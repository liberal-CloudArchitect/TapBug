# 阶段 3：领域契约与证据链验收

状态：**固定 localhost `missing_x_content_type_options` 链的真实 V2 Docker + Hermes ACP E2E
已验收。**并行、更多漏洞类型、真实资产 profile、Wheel R2.5 和质量 benchmark 未完成。

## 固定链与网络预算

现行链只支持 localhost 随机端口的 `missing_x_content_type_options` 教学 fixture：

```text
GateDecision → AssetInventory → EndpointInventory → CandidateSet
→ VerificationPlan → ApprovalBundle → VerificationOutcome
→ SignedHumanReview → ValidatedFinding → CoverageReport
→ ReportPreflightVerifier → ReportAuthorizationReceipt
→ ReporterAcknowledgement → formal report
```

Recon 固定一次 GET；Verifier 固定对 candidate/control 各一次 GET；其他角色无网络权限。
七个领域产物均为冻结的 V2 contract，绑定 run、scope、producer task 和 canonical digest。

## EvidenceArtifact V2

每份证据位于 `evidence/<evidence_id>/`，包含最后提交的 `manifest.json` 和限长、脱敏的
`analysis.json`。raw retention 默认关闭；开启时额外写入 AES-256-GCM `raw.enc`。Recon
evidence 的 approval/plan/consumption 字段为空；两个 Verifier evidence 必须分别绑定 exact
action、ApprovalBundle 和独立 consumption。EvidenceArtifact manifest 中的 `response_hash`
只绑定响应内容，不能再退化为“request 或 response 任一个 hash”。

默认 capture limit 为 1 MiB、analysis limit 为 64 KiB，硬上限分别为 10 MiB 和 256 KiB。
manifest 中的 `analysis.limit_bytes` 限制的是序列化后的整个 `analysis.json` 文件，而不只是
响应 body 字段。header、query/form/JSON/text 按规则脱敏；binary/未知 MIME 不保存正文分析。
权威 accepted run 的三份 analysis 文件为 `579 / 592 / 592` 字节，均低于 `65536` 字节。

## 报告硬门

PromotionService 和 ReportPreflightVerifier 只从 canonical 路径加载 artifact。preflight 检查：

- run/scope/task/action/plan/candidate digest 链连续；
- ApprovalBundle 签名、usage、TTL、exact plan 与两个一次性 consumption；
- 三份 evidence manifest、analysis hash、完整 binding 和精确集合；
- 父运行时和 preflight 从受 manifest hash 保护的 `analysis.json` 重新推导语义，而不信任
  agent 的声明：Recon 响应必须包含合法 negative-control `Link`，candidate 必须缺少
  `X-Content-Type-Options`，control 必须为 `nosniff`，且两次验证响应都为 HTTP 200、正文相同；
- VerificationOutcome、ValidatedFinding、CoverageReport 引用集合完全相同且计数守恒；
- SignedHumanReview 的签名、outcome digest、draft digest 和 accepted verdict；
- evidence/finding/consumption 目录不存在额外正式 artifact。

preflight 生成带 verifier ID、schema version、时间和全量输入 digest 的可重算 receipt。Reporter
只能返回绑定该 receipt 的 acknowledgement；`write_report` 随后再次运行 preflight。任何失败
时 Reporter 调用数必须为 0，`report.md`、`findings.json` 和 receipt 都不得出现。

## V1 隔离

V1 artifact 只允许列出 metadata、校验历史 hash/签名和导出审计摘要。公开 `start`/`resume`
入口在启动任何角色前即返回 `legacy_run_read_only`；approval 变更、`review sign`、
PromotionService 和 Reporter 同样 fail-closed。不得补写 analysis/raw 或重新生成报告。

## Docker 错误辨析

- 早期 `/secure/hermes-e2e-artifacts` 报 `Read-only file system`，原因是示例绝对路径在该
  主机不可写；使用仓库内 `$PWD/artifacts/...` 或实际可写的绝对路径即可。
- Codex 默认沙箱内访问 Docker socket 报 permission denied，是宿主沙箱对 Docker API 的权限
  限制；获准的宿主执行已证明 daemon、镜像和容器链可用，当前验收不再受此阻断。
- 早期复跑中的 HTTP 402 发生在 Docker 角色向父运行时请求 Hermes ACP 推理之后，
  属于模型 provider 计费/entitlement，和 Docker socket、容器网络或 pinned transport
  无关。该 402 是已解决的历史 provider 问题。
