## 防绕过保证

V3 的 report preflight 会从 canonical artifacts 重新计算路由、去重、reviewer 分配和 ledger 链，
并核验 manifest、approval、consumption、证据、cleanup、coverage、人工签名和 provider metadata。
任一授权、证据、预算、ledger、复核、coverage 或 cleanup 链缺失或篡改时，回归要求 Reporter
调用次数为 0，且正式报告文件不存在。

固定 fixture 的安全语义也由父运行时从 Evidence analysis 重新断言：模型不能以自由文本覆盖
endpoint、action、证据绑定或固定正/反对照结论。ACP 只接收结构化 JSON（单个 JSON fence 可被
规范化），并在 V3 verifier 手交前由父运行时绑定 run/scope/task/campaign/approval 等外层权威字段。
