# 阶段 5：V4 安全检测与可复核报告

当前状态：**实施中，尚未验收为产品能力。**

V4 是与 V2、V3 和 R2.5 工件隔离的 localhost-only 工作流。它扩展固定教学靶场的八类候选：
`missing_x_content_type_options`、`insecure_session_cookie`、`exposed_debug_endpoint`、
`unvalidated_redirect`、`cross_tenant_object_read`、`unauthorized_graphql_mutation`、
`privilege_escalation` 和 `workflow_transition_bypass`。

## 已实现的边界

- `RunPlanV4`、V4 prompt registry、九份 role manifest、32 请求/48 ACP attempts/12 美元上限；
- TLS 显式 CA 信任、Cookie/header posture、局部 OpenAPI projection 与外部 `$ref` 拒绝；
- 固定 26 个批准验证动作及 2 个 discovery 预算，双身份 alias/binding、无跟随 redirect、mutation cleanup 图；
- 两次受 policy/pinned TLS 约束的 discovery（Recon target、Mapper OpenAPI）以及 26 个审批验证动作，
  因而全量路径的总数为 28；同时具备 V4 Action/Budget Ledger、approval consumption、EvidenceArtifact
  V2 绑定、质量数据集和质量收据；
- 包含复现、前置条件、影响、修复、严重度、VRT/CVSS 与 coverage appendix 的报告模型；
- Reporter 启动前和写入前都重新执行 V4 preflight；未提供真实 approval/review 验签器时 fail-closed。
